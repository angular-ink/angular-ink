# angular-ink

Terminal apps (CLIs and TUIs) built with Angular components: flexbox layout with Yoga, keyboard
and focus as signals, and redraws of only the cells that changed. Its own engine with an API
inspired by Ink, for Angular. It does not wrap Ink or React.

**Status:** in development. This version has no functionality yet; the first release will be
published under this name and the `@angular-ink` scope.

Not an official Angular project.
